# Pictogramas que faltan en el banco para «Safari de las Sumas»

Petición para el banco de pictogramas propios de Fönia (`~/Developer/pictogramas-propios`). La app solo usa pictos del banco: donde falta uno, hoy sale el más cercano. Cuando estén hechos, se cambia en `EMO` (index.html) y se borra de esta lista.

| Falta | Hoy se usa | Para qué |
|---|---|---|
| abeja | miel | marca Colmenia |
| bombilla / idea / pista | mirar | botón «Pista» |
| trofeo | copa | campeonato y diploma |
| búho (guía) | pensar | «Aprendemos juntos» |
| campamento / tienda de campaña | casa | meta de la misión |
| jeep / todoterreno | coche | jeep de la misión |
| palitos (varios palos) | palo | representación con palitos |
| marco de 10 (cuadrícula) | caja | representación marco de 10 |
| números tres, cuatro, seis, siete, nueve, diez (solo hay uno, dos, cinco, ocho) | cifra en texto | números grandes |
| mano con 3 dedos, mano con 4 dedos (hay mano uno, mano dos y mano abierta = 5) | — | «Mis dedos» |
| esqueleto de la mano / huesos de los dedos | — | «Mis dedos» |
| pinza (pulgar e índice juntos) | coger | «Mover y juntar» con la mano |
| dado | otra | «otra suma» |
| sonido / altavoz | oír | botón de sonido |
| imprimir / diploma | papel | diploma |
| pantalla completa | pizarra | botón de pantalla completa |
| cerebro | cabeza | «el número grande en la cabeza» |
| aplauso | estrella | celebración |
| selva, sabana, volcán | árbol, flor, fuego | niveles |
| sumar | signo más | — |
| siguiente | derecha | botones «Siguiente» |
| juntar | ayuda | botón «Juntar» |
| apagar | parar | apagar la cámara |
